# Phy-Basic-Experiments
中山大学物理与天文学院基础物理实验一和基础物理实验二的每个实验的实验报告模板


>本实验报告合集为中山大学物理与天文学院的基础物理实验一二的实验报告模板，原实验模板来自[huanyushi学长](https://github.com/huanyushi/SYSU-SPA-Labreport-Template)，笔者针对学校的实验讲义进行相应内容的填充和修改。
>
>你可以用来：
>
>1、完成对应实验的tex报告，根据自己的思考和实验内容在tex代码上进行填充和修改（推荐）
>
>2、打印出来手写填充，模板里在相应的位置里留有空白，适合手写。但是留白的大小不一定适合你，建议只打印前面实验器材原理等比较通用的内容。
>
>注意：用本模板时注意核查，可能其中有内容和格式的疏漏，欢迎在[GitHub](https://github.com/yuanx57/Phy-Basic-Experiments/issues)上指正。
>
>
>为什么要提供这些模板？\
写实验报告大部分时间是在调整格式和把讲义上的内容搬到报告上，耗时耗力。希望报告模板能够让大家更加专注于对实验内容和相关题目的思考本身。
